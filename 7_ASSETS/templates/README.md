# Video templates (rebuilt on native_composer)

The legacy HyperFrames render-project templates were retired (2026-06-25). The library is
being rebuilt as **scene-structure templates** for `4_BRAIN/native_composer.py` — see
`6_SOP/REFERENCE_TO_VIDEO_SOP.md`. A template = a reusable scene structure (component types,
accent rhythm, kicker hints) with NO content; the Scene-Composer fills it per topic (ADAPT mode).
The old HTML render-project templates were retired and removed (replaced by these JSON templates).
