# Talking-Head Craft Analysis — GROUP 3 (8 videos)

Frame-level edit-craft teardown. All observations are grounded in extracted frames
(6 per video) saved to the scratchpad frame folder (see bottom). Contact sheets
`sheet_g3_1.png` … `sheet_g3_8.png` were inspected by eye.

## KEY UP-FRONT FINDING — these 8 files are STYLE VARIANTS of ONE clip

All 8 videos are the **same voiceover / same script**, re-skinned in 8 different
motion-graphic template styles. The shared script (read off the captions across all
variants) is:

> "As a computer science graduate … this genuinely blows my mind … Fable and
> Higgsfield took hand tracking … the velocity prediction … the physics … and a
> fully [autonomous …]"

- **Videos 1–7 share the SAME footage take** (presenter in a light-blue oxford/polo,
  RØDE-style broadcast mic, MacBook on a clean desk, neutral studio).
- **Video 8 is a DIFFERENT take** (same presenter, but darker denim shirt, warm
  ring-light + two table-lamps, dark ambient set). It reuses the doodle concept of #6
  on new footage.

So this is a **template A/B showcase**: identical content, 8 distinct treatments.
Extremely useful as a "one script → N looks" reference set. Format specs are
identical across all 8:

- **Aspect / resolution:** 9:16 vertical, **600×1066**.
- **FPS:** 24.
- **Duration:** 7.5s (video 4 = 8.67s).
- **Cut rate:** effectively single continuous take per file — no hard cuts; all
  "editing" is graphic/typographic layers animating over one talking-head shot
  (medium cut rate feel via caption + graphic swaps every ~1–1.5s).

## Video 1 — `4b4f39a7-042a-46a3-9e7c-acf9ea8cc70b.mp4`
**Mode:** Editorial / kinetic — **3D "OS desktop" object motif** (framed speaker inside a floating window).
Frames: `g3_1_t1.0.jpg` … `g3_1_t7.0.jpg`.

- **HOOK:** speaker composited as a **cut-out portrait inside a 3D app-window card**
  that floats over a solid-color stage (green, red, slate, gold rotate per beat).
  Caption "computer graduate" bottom-of-card. No separate title card — the window
  frame itself is the hook device.
- **CAPTIONS:** 2 words/cue, **bold white lowercase**, sitting at the base of the
  window card (well clear of the mouth, which stays in the card's upper half). Two
  highlight treatments seen: **solid white chip with black text** ("hand tracking")
  and **yellow tinted keyword** ("the **velocity** prediction", yellow on white).
  Face/mic avoidance solved structurally — the caption lives on the card's bottom
  margin, never over the face.
- **CARDS / GRAPHICS:** the whole language is **3D claymation-style UI props** —
  window chrome with traffic-light dots, a pixel CRT monitor, a pixel chat bubble,
  rows of toggle switches, green knob/slider control panels, a big pixel hand-cursor,
  stacked browser windows, an atom-ring. Props orbit the speaker card and change per
  topic (toggles for settings, knobs for "hand tracking", slider for "velocity").
- **BIG-WORD / KINETIC type:** no — type is small/secondary; the 3D props carry the
  kinetics.
- **B-ROLL:** none; speaker is always the framed inset.
- **MOTION:** props pop/parallax in; card + background swap color per beat.
- **PALETTE:** saturated primaries as full-bleed backdrops (kelly green, red, gold,
  slate) + white UI props with green/pink accents.
- **SAFE-ZONE:** best-in-group — the speaker is boxed into a card so captions and
  props occupy the guaranteed-empty stage around it.
- **DISTINCTIVE / reusable:** "speaker-in-a-window card on a color stage, ringed by
  topic-matched 3D UI props." The card frame is what makes captions trivially safe.

## DO SEVERAL UUID FILES SHARE A STYLE?
**No two are the same style — but all 8 share the same script/voiceover, and 1–7
share the same footage take.** This is a deliberate "one script → 8 template skins"
showcase. Loose family pairs by sensibility:
- **Doodle/analog family:** #6 (ransom-note + marker bursts) and #8 (crayon + rotoscope
  outline) — same hand-made spirit, different footage.
- **Clean-caption family:** #3 (HUD, white shadowed) and #5 (design-canvas, mint
  keyword) — most disciplined, most reusable caption systems.
- **Loud-graphic family:** #2 (balloon type), #4 (big condensed caps), #7 (green pop)
  — type/props as spectacle, lower word density.
- **#1** stands alone: the speaker-in-a-window card metaphor.

## 3–5 DISTINCT REUSABLE CRAFT PATTERNS ACROSS THE 8

1. **Speaker-in-a-framed-card on a color stage (V1).** Compositing the presenter into
   a 3D window/card and setting it on a solid color plate makes the surrounding stage a
   guaranteed-safe zone for captions + props. The single most robust safe-zone solution
   in the group — no face/mouth collisions ever.

2. **One accent word per caption cue (V5, echoed in V1/V3).** Uppercase white base,
   exactly one keyword tinted a single brand color (mint in V5, red in V4, yellow in
   V1). Disciplined, scannable, and trivially templatable — the highest-signal caption
   pattern to port.

3. **Topic-matched graphic props that swap every beat.** Every variant rotates a
   prop/graphic per phrase tied to the word: toggles/sliders for "hand tracking", a
   speedometer + telemetry numbers for "velocity", an atom for "physics". The prop
   *illustrates the spoken noun* — reusable as a keyword→icon/prop mapping table.

4. **Data-readout HUD props (V3).** Gauges and telemetry panels showing actual numbers
   (753, 1.57, 1220 km/h) tied to the metric being described — cheap way to make a
   talking-head feel like a "technical demo" without real b-roll.

5. **Shadow/scrim caption legibility over busy backgrounds (V3 dark scrim, V7 hard
   offset shadow, V6/V8 paper-chip or marker).** Three interchangeable ways to keep
   captions readable without a solid box: soft dark scrim, hard drop-shadow, or a
   physical paper/marker substrate. Pick per background busyness.

Bonus honest note: **big-word/behind-speaker occlusion** appears in V2 (balloon type)
and V8 (rotoscope outline) — visually premium but it *costs readability/safe-zone*;
V4 avoids the cost by pushing the speaker off-center rather than layering type over the
face. Prefer the V4 approach when captions must stay legible.
