## Cross-video reusable patterns (V2 mode candidates)

1. **Chest-anchored karaoke that dodges the face.** Captions deliberately sit at *mic/chest level* (~y55-60%), not a generic lower-third, so they never touch mouth/eyes. Two flavors seen: (a) 2-line, 2-3 words/line, whole-line yellow/white alternation, no box (Khánh, V1/V4); (b) full-sentence in a black pill with a **filled yellow highlighter-box** on the keyword (Hermes, V2/V3/V7). Both worth encoding as distinct caption styles.

2. **Top-third info-card system, anchored opposite the speaker.** Cards live *above the head* (top ~30%) so they never collide with the face/hands: macOS-window spec **table** (with a status pill badge), **neon corner-bracket bullet-list**, and **step-header** cards. A reusable "card slot" driven by the semantic role of the moment (table / list / step).

3. **Screen-share tutorial layouts.** Two variants: a **full-width screen-rec BAND** across the mid with the head poking above (V3), and a hard **40/60 top-screen / bottom-presenter split** (V7). Caption rides on top of the recording. A clean pattern for how-to content.

4. **Full-screen AI b-roll + multi-tier editorial text stack** (V5, faceless): kicker pill-badge → oversized headline → numbered-list build → running caption, all keyed to **one accent color**. This is the "news/explainer" mode and is fully distinct from the talking-head modes.

5. **Big-word kinetic emphasis + icon-tiles** (V6 reference, echoed by V1/V4): the important token (a number or noun) is blown up far larger than the sentence, two-tone with an underline; plus **glowing icon-tiles with ✗/✓ badges** for yes/no beats. Strong, low-narrative-cost visual punch.

Also-worth-stealing wrappers/ornaments: **page-curl screenshot card** (V1), **gold-gradient hook with oversized decorative punctuation** (V4), **handwritten meta-annotation in the headroom** (V4), and a **purple border-frame wrap** (V7).
