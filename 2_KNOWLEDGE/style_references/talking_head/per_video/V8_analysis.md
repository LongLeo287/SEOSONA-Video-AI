## 1. THE FIVE PERSISTENT OVERLAY SYSTEMS

The video composites the speaker (single locked medium shot, handheld mic foreground) with **5 distinct overlay families**. None are b-roll; all are ASS/graphic overlays over live footage.

| # | System | Zone | Persistence | Role |
|---|--------|------|-------------|------|
| A | **Eyebrow / section pill** (top-left) — small dot + optional icon + optional circled number + LABEL | TOP-LEFT | swaps per beat/section | context anchor "where are we" |
| B | **Circled step number ①②** — first as a BIG center callout, then collapses INTO the pill | CENTER→TOP-LEFT | on section entry | chapter marker |
| C | **Accumulating checklist / reasoning card** — stack of rounded pill rows that appear one at a time and stay | TOP-LEFT (under pill) | builds, holds, resets on section change | the "argument being built" |
| D | **Reasoning line with `→`** — a secondary two-part statement joined by an arrow, above the caption or as the last checklist row | TOP-LEFT lower / above caption | per point | cause→effect logic |
| E | **Karaoke caption** — chunked, bottom, with **true active-word** highlight in orange | BOTTOM | continuous | spoken word sync |

## 3. THE STATE MACHINES (what actually advances)

### 3a. Section-pill + circled-number progression

```
S0 intro       PILL: "● XU HƯỚNG SẮP TỚI" → "● BẢN CHẤT MÔ HÌNH" → "● HỎI AI"   (no number)
S-warn         PILL: "⚠ Để ý kỹ"                                                  (amber)
S-AI-suggest   PILL: "● AI ĐỀ XUẤT"                                               (no number)
S-overseas     PILL: "Làm với thị trường nước ngoài" / "▦ Tự học trên AI"         (no number)
── numbered chapters begin ──
S1  ①  BIG ① center ("Tư vấn Luật")  ──collapse──►  PILL: "● ① TƯ VẤN LUẬT"
S2  ②  BIG ② center ("Kế toán")       ──collapse──►  PILL: "● ② KẾ TOÁN"
S3 payoff/CTA  PILL: "● GÓC NHÌN CÁ NHÂN" + save CTA                              (no number)
```

Key craft move: the circled number has **two render modes** — (1) a large centered splash on section entry (~2 beats), then (2) it **shrinks and docks** into the top-left pill as a small circled glyph prefix. Same number, two sizes, one continuous identity.

### 3b. Accumulating checklist — per-row STATE

Rows appear **sequentially, one per beat, and persist** until the section resets. Two variants:

- **Tag-list variant (AI ĐỀ XUẤT):** each row = `☑ <label>` checkbox pill; empty placeholder pills sit greyed to the right hinting "more coming". State per row: `hidden → revealed(check animates in) → held`.
- **Reasoning-card variant (① / ②):** each row = rounded pill, `<icon> <neutral text> <ORANGE accent tail>`. Rows build 1→2→3, then the whole card can **swap** to a new titled card ("Rất nhiều đội cần", "Sắp tới cực HOT") that itself may contain a reasoning-arrow row.

Reveal counts observed: 2 rows (#2), 3 rows (#11→#13), 3 rows (#28→#30), 2 rows (#44).

### 3c. Reasoning line with `→`

A distinct row type: **two clauses joined by `→`**, expressing cause→effect. Neutral body, orange on the payoff clause.
- `DN 1 người bùng nổ → nhu cầu còn cao hơn` (#31–36, held 5 frames)
- `→ Việc kế toán nhiều hơn rất nhiều` (#44–49, held 5 frames; arrow leads the line here)

It behaves like the **last / emphasis row** of the accumulating card and is deliberately held longest — it's the argument's punchline.

### 4e. Color → ROLE mapping (brand LIGHT translation)

Source palette is a dark UI (dark translucent pills, teal status dot, orange accents). Translate **meaning, not palette**:

| Source | Meaning | SEOSONA ROLE |
|--------|---------|--------------|
| Orange accent word / tail | live emphasis / payoff | **ROLE_ACCENT_CORAL #E2724D** |
| Blue title ("Doanh nghiệp 1 người", "Tư vấn Luật") | primary concept | **ROLE_PRIMARY_BLUE #2A5BDA** |
| Teal status dot | "section active" state | map to **coral dot** or brand teal-accent; keep as small state indicator |
| Amber "⚠ Để ý kỹ" | warning/attention | **ROLE_WARN_AMBER #D97706** |
| Checkbox tick | affirmed / done | **ROLE_OK_GREEN #16A34A** (recommend green tick instead of coral for "confirmed") |
| Dark translucent pill fill | glass card | LIGHT theme → **white/near-white translucent pill** `rgba(255,255,255,0.72)` + soft shadow, dark text |

**Brand caution:** source uses dark glass pills + white text. Our brand is LIGHT-only. Invert card fills to light glass with dark body text; keep coral/blue/green/amber accents. Do NOT reproduce the dark neon look.

### 4f. Timing summary

- Section = ~20-40s block. Number splash hold ~2s then morph-dock.
- Checklist rows stagger 1 per caption chunk (~1.5-3.5s apart).
- Reasoning-arrow line held longest (4-5 caption chunks) as the point's proof.
- Caption re-chunks every ~1.5-2s; active word advances continuously within chunk.

## 5. WHAT THE ENGINE CANNOT (YET) DO — GAP FLAGS

1. **Circled-number two-mode morph** (big center splash → shrink-dock into pill). Engine has static ASS boxes; the *morph/dock* animation is not expressible. Fallback: cut — show splash box, then hard-cut to pill box (no tween). **Needs: section-pill + circled-number card type** with an optional splash pre-roll.
2. **Per-row sequential reveal with retained state** (checklist that accumulates 1→2→3 and holds). Current `bullet` cards render sequentially but there is no "accumulate + hold + reset-on-section" state model, and no green-tick / checkbox prefix. **Needs: card-state ✓/progress** — a `checklist` card with per-row `{hidden|revealing|held}` and a reveal cursor tied to caption chunks.
3. **Reasoning line with `→` connector and two-clause color split.** No current card renders an inline arrow joining a neutral clause to an orange payoff clause. **Needs: reasoning-line schema.**
4. **Placeholder "empty pill" rows** hinting more items coming — not modeled.
5. **True per-word karaoke active-word** (exactly one orange word advancing). If the ASS karaoke is chunk-highlight only, this is a gap; if `\k` timing is wired, it's supported — **verify**. Keyword-accent alone (static orange keyword) is NOT the same as a moving live word.
6. **Section state as a first-class object** — the pill, circled number, checklist, and its reset are all one coordinated section state; engine currently treats each overlay independently. A `section` container that owns pill + number + checklist + reset would map this cleanly.

## 6. ONE-LINE TAKEAWAY

V8 is the corpus's reference implementation of a **stateful section system**: an eyebrow/section pill that carries a **circled step number** (revealed big, then docked), an **accumulating checklist** that builds row-by-row and resets per section, and a held **`→` reasoning line** as each point's proof — all over a single locked talking-head shot with **true active-word** karaoke. Best demonstrates: **card-state ✓/progress**, **section-pill + circled-number**, and **reasoning-line**.
