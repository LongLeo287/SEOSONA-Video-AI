# V5 — "Selling Low Ticket Digital Products" — Frame-by-Frame Craft Analysis

**Source sheet:** `8_WORKSPACE/talking_head_study/dense/sheets/05_Facebook.jpg` (1602×1510, 6×3 grid, 16 keyframes)
**Format:** vertical 9:16, ~30s, 16 scenes, talking-head + AR-style floating app-icon tiles
**Engine target:** SEOSONA talking-head engine — footage 1080×1920, 3-zone (TOP card band / MIDDLE speaker / BOTTOM karaoke), ASS overlays, brand LIGHT.
**Why this reel matters:** it is the single best reference for two features we don't yet have — the **negation tile (green ✓-state → red ✕-state grid)** and the **sequential icon-tile grid that accumulates then flips to a colored "solution" set**. It also gives a clean **money-stat hook card** and a **light-brand title slate**.

> Note: the brief's ticket description said "$30,000" hook + "glassy tiles talent grabs" — the actual on-screen stat is **"$23,700"** (frame #1). Everything else matches. Colors in the source are **dark studio + neon-green / red / purple / gold** overlays; SEOSONA must **translate meaning to ROLES, not copy the palette** (source is dark; brand is light).

## 1. FRAME-BY-FRAME TIMELINE (TOP / MIDDLE / BOTTOM per beat)

### Beat A — HOOK (#1, 0.9s)
- **TOP/overlay:** Stat card, **not** in a band — floated over lower chest (~y 1180–1420 of 1920). Two lines, left-aligned to center:
  - L1 "I left my" — white, medium weight, ~48px cap height.
  - L2 "**$23,700**" — very large bold (~150px), split color: the "$2" reads **teal**, remainder white with teal edge; thin **underline stroke** under the number.
- **MIDDLE:** speaker seated, mic right, one hand rising into frame (open gesture under the number).
- **BOTTOM:** none (the stat replaces caption this beat).
- **Entrance:** number pops in scale-up; underline draws L→R (typical of this style).

### Beat B — white flash (#2, 2.8s)
- Full-frame **white** — a hard wipe/flash used as the cut into the slate. Engine equiv = 3–5 frame white dip or a white-card crossfade.

### Beat C — TITLE SLATE (#3, 4.7s)
- **Full-frame graphic (no speaker):** light **white paper-grid** background.
- **Motif:** black **dashed S-curve arrow** sweeping bottom→top-right (upward trajectory / "the path up").
- **Two 3D iso tiles** center-upper: **gold** tile (document + graduation cap = course/education) overlapping a **green** tile (file marked "E-BOOK").
- **Title lockup** lower-third, left-aligned:
  - Line 1: `SELLING` (black) + `LOW TICKET` (white text inside a **black highlight pill**).
  - Line 2: `Digital Products` — huge black bold.
- This slate is **already light-brand-compatible** — near-drop-in for SEOSONA.

### Beat D — talk + karaoke (#4–7, 6.6–12.2s)
- **TOP:** none.
- **MIDDLE:** speaker, natural hand gestures.
- **BOTTOM/caption band (~y 560–640 region over chest, i.e. mid-frame not true bottom):**
  - Single line, centered, bold sans.
  - **Neutral/connective words = white** ("the decision came", "I was tired").
  - **Emphasis keyword = accent color** — "**Because**" GREEN (#5), "**four cl[ients]**" GREEN (#7).
  - #6 shows an **inline icon** beside the phrase ("I was tired" + small tired/slumped-person glyph) — caption can host a mini-glyph.
- **Style = keyword-accent karaoke:** phrase in white, the semantically-loaded word swapped to a role color as it's spoken.

### Beat E — NEGATION GRID accumulation (#8–11, 14.1–19.8s) ★ key feature
The pains stack up as a **sequential grid of green glassy tiles, each stamped with a red ✕** at its top-right corner. Tiles appear ON the speaker (over torso), NOT in the top band — this is an AR "floating in front of me" placement.

- **#8 (14.1s):** 1 tile — **vacation** (sun + beach umbrella), green fill, green line-icon, **red ✕** top-right. Positioned mid-left of chest. Hand gesturing below.
- **#9 (16.0s):** **row of 3** — vacation · **time** (hourglass+clock) · **people** (group of 3). Evenly spaced horizontal row across chest (~y 1050–1250). All green + red ✕.
- **#10 (17.9s):** **4 tiles** — same 3 on top row + **gym** (flexed-arm/dumbbell) added below-left, forming an L. Caption keyword "**gym**" sits just above the grid.
- **#11 (19.8s):** **5 tiles** — top row 3 (vacation·time·people), bottom row 2 (gym · **food/diet** = plate+fork/knife). Caption keyword "**even**". This is the fullest ✕-grid.
- **Entrance:** each new tile **pops in sequentially** (scale + slight glow), matching the spoken list; earlier tiles persist. Red ✕ appears with (or a beat after) each tile.
- **Meaning:** "it's not about the vacation / the time / the people / the gym / not even the food" — every tile is a rejected thing → **✕ = danger/negation ROLE**.

### Beat F — SOLUTION FLIP (#12, 21.7s) ★ key feature
The green ✕-grid is **replaced** (not ticked — swapped) by **4 NEW tiles, each a different color, NONE with a ✕**:
- **amber/gold** — gears + lightbulb (strategy / idea) — top-left.
- **purple** — pen-in-frame / design canvas — top-right.
- **green** — person at desk/laptop (digital product / creator) — bottom-left.
- **amber/gold** — `$` + rising bar chart (revenue growth) — bottom-right.
- Arranged as a **2×2 diamond** around the speaker's hands (~y 1080–1520). No ✕ = these are the answers.
- **Transition:** the ✕-set fades/shatters and the color-set fades up in its place — a clear "wrong things OUT, right things IN" beat.

### Beat G — AR GRAB (#13–14, 23.5–25.4s) ★ hardest to replicate
- The 4 solution tiles **float with motion-blur** — they are being physically "handled".
- A **white pointing-hand cursor (👆)** hovers/lands on a tile: purple design tile (#13), then green person/laptop tile (#14).
- Speaker's real hand reaches toward the tiles → reads as **grabbing/selecting** in AR space.
- This is compositing that tracks hand motion + a UI cursor — **engine CANNOT do true hand-tracked grab** (see §3).

### Beat H — PAYOFF (#15, 27.3s)
- **Caption** "low ticket" (white) over chest.
- **Single green tile** — person-at-laptop (digital product) — centered, echoing the title slate's E-BOOK/green tile.
- **Green bold label** "**Digital Products**" directly under the tile.
- Clean, singular — the chosen answer, restated. Strong callback to slate #3.

### Beat I — outro (#16, 29.2s)
- Caption "creative" (white keyword), no tiles, speaker relaxed. Soft close.

## 2. BUILD-SPEC (engine-mappable)

All coordinates in **1080×1920** space. Convert the reference's mid-chest tile band to our zones: TILE-BAND ≈ **y 980–1520** (over MIDDLE speaker zone — an AR overlay layer, above the bottom karaoke band at y≈1620–1820).

### 2.1 Icon-tile grid schema (with ✓/✕ STATE)

```yaml
tile_grid:
  layer: overlay_ar          # drawn over MIDDLE speaker zone, below caption band
  band_y: [980, 1520]        # 1080x1920
  tile:
    size_px: 150             # square, rounded corners r=28
    style: glass             # 12% white fill + inner glow + 40% drop shadow
    icon: line               # single-weight line glyph, centered, ~60% of tile
    label_optional: below    # small 28px caps under tile (rarely used here)
  state:                     # ← the core new capability
    negate:                  # ✕ badge, top-right corner
      badge: cross
      badge_color: role.danger      # coral #E2724D  (source used red)
      tile_tint: role.neutral_soft  # keep tile calm; the ✕ carries the "no"
    affirm:                  # ✓ badge, top-right corner
      badge: check
      badge_color: role.success     # green #16A34A
    plain:                   # solution tiles carry NO badge, color = role
      badge: none
  layout:
    mode: sequential_grid    # tiles pop in one-by-one, earlier ones persist
    arrange: [row3, row3+row2, grid2x2]   # 1→3→4→5, then flip to 2x2
    row_gap: 40
    col_gap: 40
    entrance: pop_scale       # scale 0.6→1.0 + fade, 180ms, ease-out-back
    entrance_stagger: on_keyword   # each tile enters on its spoken word
```

## 3. What the ENGINE CANNOT (yet) do — GAP FLAGS

1. **AR hand-grab of tiles (#13–14)** — tiles tracked to the real hand with motion-blur + pointer cursor. This needs hand tracking + per-frame compositing. **Not feasible** in ASS/native composer. **Workaround:** keep tiles static/pinned and animate a **cursor or highlight ring** onto the "chosen" tile, or do a scale-pop on selection. Fake the "grab" with a tile that scales up + moves toward center on a fixed path, not hand-tracked.
2. **Negation tile ✕-badge state** — we don't have a tile object with a **corner state badge (✓/✕)**. This is the #1 buildable win: add `state: negate|affirm|plain` → renders a coral ✕ / green ✓ / no badge in the top-right corner. **Feasible in ASS** (badge = second overlay layer per tile).
3. **Sequential accumulating grid** — tiles that **pop in one-by-one on the spoken keyword and persist** into a growing 1→3→4→5 layout, then **swap** to a 2×2. Our current cards are header/bullet/stat/term, sequential bullets exist but **icon-tile grid with retained layout + set-swap does not**. **Feasible** — extend bullet sequencing to a grid with fixed slot presets.
4. **Glass/iso 3D tiles** — source tiles are glassy with glow + 3D iso variants (slate). We can approximate flat rounded tiles with soft shadow; **true 3D iso** would need pre-rendered PNG assets (fine for the slate, which is a static graphic).
5. **Split-color number** ("$2" teal / rest ink) — per-glyph color inside one number. **Feasible in ASS** via inline color tags; low priority.
6. **Mid-frame caption band** — reference puts karaoke at mid-chest, not our bottom band. Decide: add a **"mid" caption anchor** for AR-tile videos so tiles (band y 980–1520) and captions don't fight, keeping tiles below the mid caption.

---

## 4. Priority for our build

1. **Negation/affirm tile state (✓/✕ corner badge)** — highest value, clearly demonstrated across #8–12, ASS-feasible.
2. **Sequential icon-tile grid with fixed slots + set-swap** — the "pile the pains, flip to the answer" mechanic.
3. **Stat-hook card + light title slate** — near-drop-in, reusable across many videos.
4. **Solution 2×2 with per-tile ROLE colors** (remap purple→blue).
5. **Payoff callback tile** (rhymes with slate) — cheap, high polish.
6. Defer: AR hand-grab (fake with cursor/scale), 3D iso tiles (pre-render), split-color number.
