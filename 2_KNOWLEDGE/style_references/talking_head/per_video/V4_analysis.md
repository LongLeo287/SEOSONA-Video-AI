## 4. BUILD-SPEC (engine-mappable → `cards.json`)

Target frame 1080×1920. Engine card renderer = `scripts/talking_head_edit.py` `build_ass()`; cards are ASS `BorderStyle-3` pills at `\an7` (top-left anchored) via `\pos(left,top)`; b-roll via `broll[]` (`full`/`pip`).

### 4a. Caption (mid-float — see GAP §5)
```jsonc
"caption_bottom": 380,        // engine default = BOTTOM band. This reel wants MID-FLOAT (~y1150).
"keywords": ["luyện tập","miễn phí","chia sẻ","yên tâm","public link","nhanh"],
"accent": "gold"
```
- Chunk size 4–5 (short punchy uppercase). Keyword accent = gold. Active-word = white karaoke `\k`.
- **Placement:** this reel's captions float at **~y=1150 (an2-equiv, centered, mid-frame over mic)**, NOT the 380-from-bottom safe zone. Engine currently locks the `Cap` style to `MarginV=caption_bottom` at `Alignment 2` (bottom-center) → see GAP.

### 4b. Full-screen graphic cutaways (the offer reveal, #4–#7)
These are pre-rendered motion-graphic clips, dropped in as **`broll` `mode:"full"`**:
```jsonc
"broll": [
  {"src":"assets/v4/offer_folder_1.mp4","mode":"full","t":6.6,"dur":1.9,"left":0,"top":0,"width":1080},
  {"src":"assets/v4/offer_folder_stack.mp4","mode":"full","t":8.5,"dur":1.9,"width":1080},
  {"src":"assets/v4/offer_ring_1.mp4","mode":"full","t":10.4,"dur":1.9,"width":1080},
  {"src":"assets/v4/offer_ring_2.mp4","mode":"full","t":12.3,"dur":1.9,"width":1080},
  {"src":"assets/v4/screenrec_proof.mp4","mode":"full","t":19.9,"dur":2.0,"width":1080}
]
```
- Engine `full` default is `width=W*0.92, top=H*0.16` (a content-zone overlay, NOT edge-to-edge). To truly **cover the speaker full-screen** pass `width:1080, left:0, top:0`. The overlaid clip must itself be 1080×1920 with the light-brand stage baked in.
- The label chips ("Dự án bất động sản", "Khóa học miễn phí!") are baked into the graphic clip, NOT engine cards (they're centered over the graphic, which the engine's `\an7`-only card can't do cleanly).

### 4c. Cards used (light annotations)
- `#3` rotating white square, `#2` shattered-glass, `#8–9` "Giải Thích Time…" script tag, `#6` ring header, `#7` ring bottom label = **all decorative / handwritten-font overlays baked into the graphics** — none map to the boxed `header/bullet/stat/term` templates. A `term` header pill could stand in for "Giải Thích Time…" but loses the handwritten feel.
- Nearest engine card for the offer beat = a **`header`** pill `{tag:"MIỄN PHÍ", title:"Raw Bất Động Sản"}` accent gold, but the reel deliberately uses a full graphic instead of a pill.

### 4d. SFX / entrance timing
- Cutaway entrances land on beat every ~1.9s (6.6→8.5→10.4→12.3). Pair each with `whoosh`/`swipe`; folder-drop-into-ring = `pop`; "Khóa học miễn phí!" peak = `success`/`ding`; screen-rec reveal = `notify`.
- Transition #10 = dip-to-black. Engine has no built-in dip-to-black between overlay and footage; would need a black `broll` clip or a crossfade baked into the cutaway edges.

## 5. What the engine CANNOT do (flag list)

1. **Mid-float caption.** `Cap` style is hard-coded `Alignment 2` (bottom-center) with `MarginV = caption_bottom`. This reel floats captions mid-frame (~y1150) over the mic. **No spec field exposes caption Y/alignment per-line.** → needs a `caption_align` / `caption_y` field or a second caption style. (Best demo of **caption-placement** GAP.)
2. **Centered / bottom-anchored card text.** Cards are `\an7` (top-left) only. The cutaway labels ("Khóa học miễn phí!" bottom-center of a ring) can't be produced by an engine card — must be baked into the graphic clip.
3. **True full-screen cutaway.** `broll full` defaults to a 92%-width, top=16% content-zone overlay, not edge-to-edge over the speaker. Achievable only by explicitly passing `width:1080, left:0, top:0` AND supplying a full-bleed 1080×1920 clip; there is no "replace speaker entirely / hide-footage" flag.
4. **Decorative motion graphics** (rotating white square #3, shattered-glass sting #2, orbit ring #6–7) — no primitive in the engine. Must be pre-rendered HyperFrames/After-Effects clips and overlaid.
5. **Handwritten / script-font annotation** ("Giải Thích Time…", ring labels). Engine renders one font (`Be Vietnam Pro`, bold). No per-card font override → the low-key cursive section-marker look is impossible; would fall back to a boxed pill.
6. **Dip-to-black transition** between overlay and footage — not a native transition; must bake fade edges into clips.
7. **Floating product thumbnail over the mic** (the recurring translucent asset over the mic base) — would be a `pip` b-roll, but engine `pip` forces a solid blue frame + 5px pad; can't do a borderless translucent float.

---

## 6. Buildable-mechanics ranking (highest ROI first)

1. **Full-screen graphic cutaway block** — the offer reveal (folder → stack → ring → label). Buildable now via `broll mode:full width:1080 left:0 top:0` + pre-rendered 1080×1920 light-brand clips. Biggest visual payload of the reel.
2. **Mid-float caption placement** — needs a small engine change (per-video/per-line caption Y + alignment). Best single lever this reel demonstrates.
3. **Screen-rec proof cutaway with a device frame** — `broll full` + a blue #2A5BDA framed 1080×1920 screen-rec (device-mockup GAP).
4. **Beat-locked cutaway cadence (~1.9s) + SFX pairing** — pure `t`/`dur`/`sfx_events` scheduling, no code change.
5. **Gold-accent single-role keyword system** (offer=gold, objection=coral) — already supported by `keywords` + `accent`.
