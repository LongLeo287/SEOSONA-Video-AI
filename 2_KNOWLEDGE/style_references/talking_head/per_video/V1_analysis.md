## 2. BUILD-SPEC (engine-mappable)

### 2.1 Caption (the core mechanic — highest priority)
This reel's whole identity is the **two-line accented caption**. Engine mapping:

```
caption:
  lines: 2                 # line1 = context, line2 = keyword phrase (or vice-versa)
  case: UPPER
  font: bold sans, ~64–72px cap height
  align: center
  y_center: ~1180px        # NOT bottom-1920; sits in lower-MIDDLE, above the mic
  color_base: #FFFFFF (on dark speaker) → role "ink-on-dark"
  color_accent: brand accent — the whole ACCENTED LINE/PHRASE, not per-word karaoke
  accent_line: keyword-driven (may be line1 OR line2 OR both for CTA)
  bg_flip: when behind is LIGHT B-roll → base color becomes DARK (#1a1a1a), left-aligned
```

**Engine delta vs. current karaoke caption:** current engine highlights the *active word* (word-level karaoke). V1 instead **accents an entire keyword PHRASE/LINE for the whole beat** (phrase-level, static per chunk). This is a *simpler* variant — buildable now by treating each 2-line chunk as one caption event with a `{accent_span}` field. **Placement at ~1180px (lower-middle, above mic) is different from the current BOTTOM karaoke zone** — needs a `caption_y` override / "mid-caption" placement mode.

### 2.2 Speaker "hero-grade" beat  ← main GAP demonstrator
A recurring punctuation device: at thesis/payoff lines the speaker shot gets a **duotone + glow (frame #6) / duotone + vertical scanline stripes (frame #15)** treatment.
- Map amber duotone → **brand accent-role duotone** (e.g. coral #E2724D or blue #2A5BDA tint as the "energy" role; keep light overall).
- Schema idea:
```
speaker_fx:
  mode: "hero"            # vs "normal"
  grade: duotone(role=accent)
  texture: glow | scanline_stripes
  trigger: on thesis/payoff caption events (author-tagged)
```
**CANNOT do yet:** engine has no per-segment speaker color-grade / duotone / scanline overlay. This is a NEW feature. Flag as **reasoning-line / emphasis-beat** gap — the hero grade is how the reel visually marks its "why this matters" line.

### 2.3 Full-frame B-roll cutaways (already partially supported)
- `#3–#5`: preset-list "hero title card" + real screenshots, skewed 3D → flatten → zoom.
- `#14`: laptop/device **mockup** frame on cream BG.
- Engine already has B-roll `full` mode. Deltas:
  - **3D-skew → flatten settle** entrance (perspective tilt easing to flat). NEW motion.
  - **Device mockup wrapper** (laptop/phone frame around a screen-recording). This reel uses a phone frame (#1–#2) and laptop frame (#14). **CANNOT do yet** — flag `device-mockup` gap.
  - Bright cream BG for cutaways (the one light moment) — engine can do; matches LIGHT brand nicely.

### 2.4 Term chip / pill (frame #12)
Word "PRESET" rendered as: **rounded-rect pill outline + accent fill + speech-bubble icon** to the right.
```
term_chip:
  text: "PRESET"
  shape: pill (rounded-rect, ~20px radius)
  fill/border: accent role
  icon: trailing glyph (speech-bubble)
  placement: replaces the caption line for that beat
```
Maps cleanly to the engine's existing `term` card concept, but as an **inline caption-pill** rather than a top-band box. Buildable; needs an icon slot. Flag minor: **section-pill / term-pill** — engine `term` exists but not as inline caption pill with trailing icon.

### 2.5 Decorative PIP thumbnails (frames #1–#2)
Floating reference thumbnails ("?" cards, phone-frame B-roll) around the speaker at the open. This is the engine's `pip` mode but **multiple, decoratively arranged + a phone-mockup inset**. Current `pip` = single inset. Multi-PIP decorative cluster = optional NEW.

### 2.6 Positions (approx, 1080×1920)
- Caption center: `x=540, y≈1180`. Two lines, ~90px line-height.
- Term pill (#12): centered `x=540, y≈1180`, pill ~360×110px, icon at right edge +40px.
- Full-frame B-roll: fills 0,0 → 1080,1920; mockup/panel centered with cream margins.
- Speaker: head-and-shoulders, eyes ~line 700–800px, mic foam bottom-center ~1400–1600px.
- Decorative PIPs (#1): upper-left cluster ~x120–420 / y80–520; phone inset center ~x360–720 / y560–1100.

### 2.7 Color → brand ROLE map
| Source (amber/gold) | Meaning in reel | Brand role |
|---------------------|-----------------|------------|
| amber accent word/line | keyword emphasis | **primary accent** → coral #E2724D (or blue #2A5BDA) |
| amber duotone hero grade | thesis/payoff punctuation | accent-tint duotone (keep light) |
| white caption base | neutral context text | ink `#1a1a1a`/white depending on BG |
| cream/off-white B-roll BG | bright cutaway | brand light background |
No green/amber-brand roles are exercised here (no ✓/✕, no stat-good/warn). This reel is **1-accent-color**.

## 3. GAPS the engine CANNOT do yet (flagged)
1. **Mid-caption placement (~y1180, lower-middle above mic)** — engine caption is BOTTOM-zone karaoke. Need a `caption_y`/placement override. *(caption-placement gap)*
2. **Phrase-level accent (whole keyword line colored for the beat)** — engine does word-level karaoke; need static per-chunk `{accent_span}`. *(caption-placement / emphasis gap)*
3. **Speaker hero-grade (duotone + glow / scanline stripes) per beat** — no per-segment speaker grade/texture at all. *(reasoning-line / emphasis-beat gap — NEW feature)*
4. **Device mockup wrapper (laptop/phone frame around screen-rec)** — B-roll is raw fullscreen only. *(device-mockup gap)*
5. **3D-skew→flatten entrance for panels/screenshots** — new motion recipe.
6. **Inline term-pill with trailing icon** — `term` card exists but not as an inline caption pill+icon.
7. **Multi-PIP decorative thumbnail cluster** — `pip` is single inset only. (low priority)

### NOT demonstrated here (do NOT mine this reel for these)
Multi-row bullet card with sequential reveal, ✓/✕ checkmarks, progress bar, step badges, numbered section circles, stat-number tiles, negation tiles. V1 has none of these — it is caption-forward, not card-forward.
