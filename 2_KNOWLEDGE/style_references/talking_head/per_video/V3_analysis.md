## 2. LAYOUT GEOMETRY (px, 1080×1920)

### 2a. Full-frame talking-head (Acts A, C) — engine ALREADY does this
- **TOP band (header card):** y ≈ 90–290 (top ~15%), centered, width ~940px, x-margin 70.

### 2b. Presenter-TOP / screen-rec-BOTTOM SPLIT (Act B) — **NEW, engine gap**
Measured split ratio from the sheet: presenter occupies roughly the **top ~35%**, screen-rec the **bottom ~62%**, with a thin seam.
- **Presenter strip:** y = 0 → ~672 (≈35% of 1920). Speaker framed head-and-shoulders, cropped from the full portrait feed (center-crop, scaled to fill 1080 wide).
- **Screen-rec panel:** y ≈ 700 → 1920 (≈62%). Browser capture letterboxed/scaled to 1080 wide; light margins.
- **Seam:** ~28px gap or a 1–2px rule at y≈685.
- **Step badge:** overlaid TOP-LEFT of the presenter strip, x ≈ 40, y ≈ 40, does NOT push layout — it floats over the presenter video.
- **Caption (BOT):** overlaid on the SCREEN-REC panel near its bottom, y ≈ 1620–1760, so it never collides with the demo UI's active area. Caption sits ON the screen-rec, not below it.

## 3. CARD / BADGE SCHEMAS (engine-mappable)

### 3a. `header` card (existing type — confirmed usage)
```
type: header
tag:      "API KEY FREE" | "TRẢ PHÍ = TỐN KÉM" | "MODEL FREE #1" | "DÙNG CHO HERMES"
headline: <same line, bold>
subhead:  <thin small line, gray/secondary>   e.g. "hệ thống Hermes AI Agent siêu tiết kiệm"
position: TOP band, centered
border/role color: see §4
entrance: slide-down + fade (source), 6–10 frames
```
Cadence: header swaps at each **content phase** (hook→problem→model→payoff), roughly every 8–12s. Header persists across several caption chunks (it is phase-scoped, not caption-scoped).

### 3b. `step-badge` (**NEW type — engine GAP**)
```
type: step_badge
label:    "BƯỚC {n}"          # BƯỚC 1 / 2 / 3 / 4
subtitle: <short step goal>    # "Google AI Studio → make API key"
          # small caps micro-crumb line under the number, may show a → breadcrumb of sub-steps
position: TOP-LEFT of presenter strip, x≈40 y≈40 (NOT centered)
shape:    rounded pill / tab with a bracket-frame edge (neon in source → brand border)
entrance: slide-in from left + fade
persistence: stays pinned for the WHOLE step (multiple caption chunks), then swaps to next n
progress semantics: monotonic counter 1→2→3→4; implies a progress bar could accompany
```
Distinct from `header`: step-badge is **top-left corner-anchored, persistent per step, counts up**, and co-exists with the split layout. Header is centered, phase-scoped, full-frame.

### 3c. `bullet`/info card (existing type — confirmed at #37–42)
```
type: bullet
title: "MỘT TÀI THIỆT NHIỀU KEY"   (tip/insight header)
rows:
  - "1 Google = 10 project / 10 key"
  - "3–4 tài khoản Google"
  - "30–40 key ... dùng thoải mái"
reveal: rows appear sequentially (row-by-row over #37→#42, ~1 row per 1.8s)
position: overlaid, mid-frame over the split (semi-card)
role: this is a "PRO TIP / multiplier math" insight card
```

## 4. COLOR → ROLE MAP (translate dark source → LIGHT brand)

| Source cue | Semantic ROLE | SEOSONA brand color |
|------------|---------------|---------------------|
| Neon-cyan/blue badge edge on step pill & headers | primary / structural / step | **blue #2A5BDA** |
| Red figures in billing screenshot ("cost/pain") | cost / warning / negation ("TRẢ PHÍ", "không") | **amber #D97706** (warning) or **coral #E2724D** (pain/negation) |
| Green figures / "FREE" / "valid" checks | success / free / valid | **green #16A34A** |
| Coral/orange accent on keyword captions | attention keyword accent | **coral #E2724D** |
| Gray subhead text | secondary / muted | brand gray/secondary |

**Border-color = ROLE rules:**
- Step badge + header (structural) → **blue** border.
- "Cost / paid / don't" tiles → **amber/coral** (negation-tile candidate: "TRẢ PHÍ = TỐN KÉM").
- "Free / valid / success" → **green** (e.g. BƯỚC 4 "check valid", "MODEL FREE").
- Caption keyword accent → **coral** for the emphasized token (API **key**, **Gemini**, **Hermes**).

## 5. TIMING RULES (extracted)

- **Header swap cadence:** ~every 8–12s at content-phase boundaries (#4→#6→#16→#50).
- **Step badge dwell:** BƯỚC 1 (#19–24, ~11s), BƯỚC 2 (#25–29, ~9s), BƯỚC 3 (#30–33, ~6s), BƯỚC 4 (#43–48, ~9s). Each step 6–11s; badge persists whole step.
- **Bullet reveal:** ~1 row / 1.8s (matches caption chunk cadence ~1.8s/chunk).
- **Caption chunk:** ~1.8s each (53 scenes / 96s ≈ 1.8s), 4–7 words, one keyword accent.
- **Split engage/disengage:** split turns ON at first step (#19), OFF at payoff (#49). Entrance ~8 frames slide.
- **Proof inset (#10–13):** ~5s window while speaker stays full.
