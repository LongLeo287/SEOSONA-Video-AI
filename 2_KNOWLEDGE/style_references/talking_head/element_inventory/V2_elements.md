## SIGNATURE ELEMENTS (the 3–5 that define this reel's look)
1. **Cyan neon bracket-corner HUD frame (5c)** — wraps every top-band graphic; the reel's core visual identity.
2. **Dark navy glass HUD banner with glowing-dot bullet (1c/1d/1f template)** — reused 3× as section headers/CTA; the workhorse panel.
3. **Faux macOS spec window with traffic-lights + gold FREE badge (1b + 5a + 5b)** — the "proof" moment that anchors the announcement.
4. **Two-color karaoke caption (2a/2b)** — green=brand, amber=number; consistent semantic color system.
5. **Blue app-logo card with white whale + V4 FLASH label (1a + 4a)** — the branded hero tile that opens the reel.

**Brand takeaway for SEOSONA remap:** keep the STRUCTURE (bracket frames, glass banners, spec window, checklist card, karaoke captions, semantic color coding) but invert the palette from dark-neon to LIGHT — frosted-white glass, blue (#2A5BDA) hairlines + soft shadows instead of cyan glow, coral (#E2724D) for CTA emphasis, green for "free/brand", amber for numbers/offers. Never dark mode. Replace every neon glow with a soft drop-shadow.
