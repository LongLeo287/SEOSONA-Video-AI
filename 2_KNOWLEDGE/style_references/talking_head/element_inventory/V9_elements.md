## Signature elements (the 3-5 that DEFINE this reel's look)

1. **Neon glass dept/role panels with a colored icon per row** (P2/P3 + I1) — the reel's core visual grammar; rows accumulate as narration builds the "company."
2. **Green-✓ numbered checklist card with progress** (P5 + I2 + D3/D4) — the "AI auto-does-the-work" proof beat.
3. **Gold "24/7" hero badge** (G1 + T4) — the single premium punchline frame; the only warm/gold moment.
4. **Uniform small-caps header + divider on every panel** (T2 + D2) — the consistent "control-panel" chrome that ties all panels together.
5. **Cyan/violet neon edge-glow on everything** (D1) — the signature finish → in SEOSONA light-brand this becomes a soft neutral shadow + thin brand-tint border.
