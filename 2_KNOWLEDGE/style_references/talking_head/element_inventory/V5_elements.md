# V5 "Selling Low Ticket" — Visual Element Inventory

**Reel:** V5 Facebook, EN, ~30s, 21 scenes (talking-head, dark studio, single subject in cap + black tee, vertical RGB light bar behind, mic frame-left).
**Focus:** every small visual element LAYERED over footage — the on-footage vocabulary, not the 3-zone caption layout.
**Signature look:** glassy green icon-tiles with red ✕ badges that accumulate into a grid, then a 3D iso-cube cluster the subject "grabs" with a cursor, wrapped by a hand-drawn dashed arrow, a title-card open/close, and a full-frame green duotone climax.

Position-zone shorthand: **Lower-third** (caption band ~65–80% height), **Mid-torso** (icon tiles over chest/hands ~45–65%), **Full-frame** (edge-to-edge), **Title-card** (white insert scenes #3–4).

## SIGNATURE ELEMENTS (the 3–5 that DEFINE this reel)

1. **Glassy green icon-TILE + red ✕ badge, accumulating into a grid** (§1 I-1…I-6 + G-1) — the single most repeated, most identity-defining motif: a "negative checklist" of pain points building up over the chest.
2. **3D isometric cube cluster the subject "grabs"** (G-2 + cursor C-1) — glossy multicolor product-cubes flying with motion blur, interacted with via a hand cursor.
3. **Hand-drawn dashed curved arrow on a grid title-card** (D-1 + D-2 + D-3) — the sketchy S-path + graph-paper intro that frames the whole "journey to the offer."
4. **Chromatic money-stat pop** (T-1) — oversized "$16.35 / $30,000" with color-split glow as the hook.
5. **Full-frame green duotone climax wash** (D-4) — the abrupt green-tint reveal that visually punctuates the offer.

## SEOSONA LIGHT-BRAND REMAP

Global rules: keep everything LIGHT; neon/inner-glow → soft diffuse shadow; dark studio → the footage stays but overlays read on light; no dark-mode panels.

| Source element | Source colour/effect | → SEOSONA remap |
|---|---|---|
| Glass icon tiles (I-1…I-7, P-1) | translucent GREEN glass + neon glow | **coral or amber** tile for "pain/avoid" tiles (negative role); glass → **soft white/light-tint card** with 1px light border + soft shadow (no neon) |
| Red ✕ badge (G-1) | saturated red disc | keep a **red/coral** disc for the "don't" semantic (red is universal for negation) — soften glow, add soft shadow |
| Keyword karaoke highlight (T-2/T-3) | teal/green active word | **blue #2A5BDA** active word (primary role) or **coral #E2724D** for emphasis words; drop glow |
| Money-stat chromatic pop (T-1) | white + teal/coral split, glow | **blue base + coral accent** split, glow → soft shadow |
| 3D cubes (G-2, G-3) | gold/purple/green/teal glossy | recolor to **blue / coral / green / amber** brand quartet; keep gloss but light-key (no dark ambient) |
| Marker swipe bar (G-5/T-4) | black highlight bar | **blue** highlight bar with white text (light-brand emphasis) |
| Dashed arrow (D-1) | black sketch line | **coral** dashed stroke (warm accent guides the eye) on white |
| Grid card bg (D-2/D-3) | white grid, page-curl | keep white; grid tint → very light **blue-grey**; brand it |
| Green duotone climax (D-4) | intense full-frame green | **soft green duotone** (success role) at lower opacity OR **blue** wash — reduce saturation to stay light |
| Cursor (C-1) | white hand pointer | keep white/light; optional **blue** hover-ring |
| Offer title serif (T-5) | white serif | brand type; **blue/coral** per hierarchy |
| RGB practical light (D-5) | white→green bar | brand as soft **blue→green** vertical gradient accent |

Colour-role legend: **blue** = primary/brand/keyword · **coral** = emphasis/warning-warm/CTA accent · **green** = success/reveal/offer-positive · **amber** = secondary attention · **red/coral** = negation (✕).
