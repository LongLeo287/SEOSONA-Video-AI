# Short-form video — named hook formulas + structures

Distilled + re-skinned for SEOSONA faceless SEO/marketing shorts (45–60s, VN voice).
Source: `coreyhaines31/marketingskills` (skills/social/references/short-form-video.md) · MIT · adopted 2026-07-02.
Use with `[[marketing-psychology]]` (pick a lever) and `MASTER_VIDEO_SPEC` (HOOK rules). Feeds
`script_writer` plan + write. Examples are VN because the hook IS the video's first spoken line.

## 4 named HOOK types (choose one; write 2 for A/B)
1. **Curiosity** (best for engagement) — hint a hidden cause/method.
   - "Bí mật [kết quả] mà không ai nói cho bạn."
   - "Tôi thử [việc] 30 ngày và kết quả KHÔNG như tôi nghĩ."
   - "Lý do [điều quen thuộc] không hiệu quả là…"
2. **Value** (best for saves) — a concrete promise or a warning.
   - "Cách [đạt kết quả] trong [thời gian cụ thể]."
   - "[Số] điều bạn cần biết về [chủ đề] trong 60 giây."
   - "Ngừng làm [thói quen phổ biến] — đây là lý do."
3. **Story** (best for watch-time) — a transformation or a mistake.
   - "3 tháng trước tôi [trạng thái xấu]. Hôm nay tôi [trạng thái tốt]."
   - "Tôi từng nghĩ [niềm tin cũ]. Rồi [sự kiện] thay đổi tất cả."
4. **Controversial** (best for comments) — a bold, defensible claim.
   - "Quan điểm ngược dòng: [khẳng định mạnh]."
   - "[Lời khuyên phổ biến] thực ra là SAI."
   - "Đa số [đối tượng] hiểu sai điều này."

## Script skeleton (per scene, with timestamps)
```
HOOK  (0–3s)  : visual + first spoken line + on-screen hook text (full at frame 0)
BODY  (3–~50s): beat → beat → beat, one idea per scene (~4–6s), each earns the next
CTA   (last 3–5s): one strong closing line + follow SEOSONA + on-screen CTA text
NOTES : music/SFX cue · b-roll/screenshot · graphic per scene
```

## Named structures (pick by content)
- **Story Arc (45–60s)** — best for cases/testimonials:
  `[0–3s] Hook: tease outcome · [3–15s] Setup: context+stakes · [15–45s] Journey · [45–55s] Resolution · [55–60s] Lesson/CTA`
- **POV / Skit (15–30s)** — best for a relatable scenario:
  `[0–3s] Setup (text overlay) · [3–25s] act it out · [25–30s] punchline/twist`
- **List / Value (30–45s)** — a numbered payoff: hook the count → deliver each item fast → CTA.

## Rule
Keep it VN, natural, grounded — the hook must promise ONE concrete benefit or plant ONE question, and
every specific number/name must trace to a real source (traceability gate). No AI-slop openers.
