## Kịch bản (display form — RULE #1)

0. **[Claude Code / nhớ cách làm?]** Bạn muốn Claude Code nhớ và lặp lại đúng cách làm của bạn?
1. **[Skills / kinh nghiệm → năng lực]** Skills giúp biến kinh nghiệm thành năng lực tái sử dụng.
2. **[Đóng gói / 1 lần dùng mãi]** Đóng gói quy trình một lần, dùng lại mãi mãi.
3. **[Tạo skill / vài bước]** Tạo một skill chỉ với vài bước.
4. **[Gọi lại / bất cứ lúc nào]** Sau đó gọi lại bất cứ lúc nào.
5. **[Làm lại / hay dùng skill?]** Làm lại từ đầu thì mệt, có skill thì nhanh.
6. **[Miễn phí / có sẵn]** Miễn phí, có sẵn trong Claude Code.
7. **[Theo dõi SEOSONA / xem thêm]** Theo dõi SEOSONA để học thêm về Claude Code.
