# Biến mọi file thành Markdown chuẩn cho AI

- **Chủ đề (template):** `tool-walkthrough` — Công cụ chuyển đổi tài liệu
- **Nguồn dữ liệu:** GitHub `microsoft/markitdown` — 159,295★, Python, MIT (số liệu THẬT, fetch lúc render)
- **Output:** `8_WORKSPACE/clones/file-to-markdown.mp4`

## Kịch bản (DISPLAY form — RULE #1)

0. **[Nạp file vào AI / đúng chuẩn?]** Bạn muốn nạp PDF, Word, Excel vào AI mà vẫn giữ nguyên cấu trúc?
1. **[Microsoft / MarkItDown]** Microsoft vừa ra công cụ biến mọi file thành Markdown cực chuẩn.
2. **[Mọi file / → Markdown]** MarkItDown chuyển PDF, Office, ảnh và cả link YouTube sang Markdown.
3. **[Cài đặt / 1 lệnh pip]** Cài đặt và dùng chỉ với vài dòng lệnh.
4. **[Định dạng / được hỗ trợ]** Hỗ trợ rất nhiều định dạng đầu vào khác nhau.
5. **[Thủ công / hay tự động?]** Copy thủ công thì rối, MarkItDown thì sạch và tự động.
6. **[Miễn phí / & mã nguồn mở]** Hoàn toàn miễn phí, mã nguồn mở với giấy phép MIT.
7. **[Theo dõi SEOSONA / xem thêm mỗi ngày]** Vào GitHub MarkItDown để thử ngay. Theo dõi SEOSONA xem thêm thủ thuật.
