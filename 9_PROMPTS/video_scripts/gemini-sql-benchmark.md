# Gemini vượt 80% benchmark viết SQL

- **Chủ đề (template):** `benchmark-news` — Tin benchmark nhiều con số
- **Dữ liệu:** hand-authored (tin/khái niệm — không phải repo)
- **Output:** `8_WORKSPACE/clones/gemini-sql-benchmark.mp4`

## Kịch bản (display form — RULE #1)

0. **[Gemini SQL / 80% benchmark]** Gemini vừa vượt mốc tám mươi phần trăm benchmark viết SQL.
1. **[Hỏi tự nhiên / ra SQL chuẩn]** Bạn hỏi bằng ngôn ngữ tự nhiên, nó trả về câu SQL chuẩn.
2. **[Con số / ấn tượng]** Những con số ấn tượng từ Gemini SQL phiên bản hai.
3. **[Tay hay AI? / đâu nhanh hơn]** Viết SQL bằng tay thì mệt, hỏi Gemini thì nhanh gọn.
4. **[Vì sao / đáng chú ý]** Vì sao Gemini SQL hai đáng chú ý.
5. **[Bước tiến / truy vấn AI]** Một bước tiến lớn cho truy vấn dữ liệu bằng AI.
6. **[Nhanh & chính xác / đa CSDL]** Nhanh, chính xác, hỗ trợ nhiều cơ sở dữ liệu.
7. **[Theo dõi SEOSONA / xem thêm mỗi ngày]** Theo dõi SEOSONA để xem thêm tin AI mỗi ngày.
