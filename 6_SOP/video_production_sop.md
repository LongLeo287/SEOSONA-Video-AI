# 📜 Standard Procedure (SOP): SEOSONA Video Production

This document specifies the standard data processing flow (Input/Output) for the entire SEOSONA Video System, strictly following the SEOSONA OS operating system philosophy.

## 1. Workspace
Each video project must be in a separate space at `8_WORKSPACE/<project_name>`.
Absolutely prohibit writing files outside the project directory or creating junk folders such as `.temp`, `SRT_temp`.

Standard structure of a project (automatically generated by `project_generator.py`):
```text
8_WORKSPACE/
└── <project_name>/
├── metadata.json (Status tracking)
    ├── assets/
│ ├── audio/ (Contains TTS voice.mp3 file)
│ └── images/ (Contains Screenshots, Thumbnails)
├── scripts/ (Contains script .txt files and subtitle .srt files)
└── renders/ (Contains hf_render folder and final .mp4 video)
```

## 2. Input Standards
- **Script:** Only accepts utf-8 text. Required to go through `_apply_lexicon_filter` to Vietnameseize borrowed English words before calling TTS.
- **Parameters (Params):** `brand`, `mode`, `aspect_ratio`.

## 3. Output Standards
- **Video:** The file `renders/hf_render/` is generated by HyperFrames and outputs `.mp4` to the root of the project directory.
- **Database:** Any rendering operation (success/failure) must be logged by `db_manager.py` to `video_os.db`.

## 4. Responsibilities of Agent (Orchestrator)
It is the responsibility of the Orchestrator Agent to read this SOP carefully before scheduling and coordinating Skills. All file paths passed to Skills (TTS, Whisper, HF) must comply with the corresponding `assets` or `scripts` directory branch.
