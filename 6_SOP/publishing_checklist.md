# SOP: Publishing Checklist

## General Checklist (All Platforms)

- [ ] Video passed Quality Scorer (score >= 70/100)
- [ ] Thumbnail generated with correct aspect ratio
- [ ] SRT file exported in standard .srt format
- [ ] File names match project name (no special characters)
- [ ] 100% Light Mode — no dark backgrounds
- [ ] Brand logo watermarked in video
- [ ] SFX variety (no repeated single sound)
- [ ] **Verified `Bao_cao_chat_luong.md`**: Reviewed Machine Learning feedback and quality score before publishing.

---

## YouTube (Long-Form — 16:9)

- [ ] Title: 60-70 characters, keyword first
- [ ] Description: Includes Timestamps, Resources, CTA
- [ ] Tags: 15-20 tags, primary keyword first
- [ ] Thumbnail: 1280×720px, < 2MB
- [ ] End Screen: Link to related video
- [ ] Cards: Placed at Retention Hook point
- [ ] Playlist: Added to relevant playlist

## YouTube Shorts (9:16)

- [ ] Duration: 15-60 seconds
- [ ] Thumbnail: 1080×1920px
- [ ] Title: Short + hashtags
- [ ] Subtitles within Safe Zone (not blocked by platform UI)

## TikTok (9:16)

- [ ] Duration: 15-60 seconds
- [ ] Caption: < 150 characters + 5 hashtags
- [ ] Audio: Check music copyright
- [ ] Trending sounds: Consider using trending audio

## Instagram Reels (9:16)

- [ ] Duration: 15-90 seconds
- [ ] Caption: Includes CTA + hashtags
- [ ] Cover image: Select best frame or upload Thumbnail
- [ ] Location tag: Add if relevant
