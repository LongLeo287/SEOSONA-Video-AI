# SEOSONA Video: SEO & Content Strategy

> Extract source: `SEOSONA OS/4_AGENTS/personas/seo-specialist.md` and `content-creator.md`

## 1. Content Strategy (Video Script)
- **AIDA Model**: All Video scripts (especially Short/Reels/TikTok) must strictly comply with AIDA (Attention - Interest - Desire - Action).
- **Hook (first 3 seconds)**: Must be sensational, stating directly the user's "Pain point" or "Implicit truth" (Insight).
- **Body Content**: Conveys information in the form of Bullet points or a clear list.
- **Call-to-Action (CTA)**: Always ends with a single action (e.g. "Subscribe to see more", "Visit seosona.com").

## 2. YouTube Metadata SEO
- **Title (Title)**:
  - Structure: `[Main Keyword] — [Benefits/Results] ([Year])`
  - For example: `Open Design | Claude Design Replacement Instructions (2026)`
  - Length: Under 70 characters to avoid being cut off.
- **Description**:
  - The first 1-2 lines must contain the Main Keyword (Optimize CTR).
  - There must be a `📌 TIMESTAMPS` section to create Sitelinks on Google Search.
  - There must be a `🔗 RESOURCES` section pointing to the website or satellite article.
- **Hashtags**: Only use a maximum of 3 Hashtags in the Title area.

## 3. Semantic & LSI Keywords
- Agents when generating scripts or tags should not only use seed keywords, but must expand to LSI (Latent Semantic Indexing).
- For example: Instead of just using "Web design", use "UI/UX interface", "Conversion optimization", "SEO standard website".

## 4. Entity & JSON+LD
- It is recommended to create a JSON+LD (VideoObject Schema) block to allocate to the satellite website when embedding this Video in an article.
