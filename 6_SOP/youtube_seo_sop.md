# SOP: YouTube SEO Optimization

*Inherited from SEOSONA OS Skill: `seo_marketing/video_content` — YouTube SEO section*

## 1. Title Formula

```
[Primary Keyword] — [Benefit/Outcome] ([Year or Number])
```

**Title Rules:**
- Primary keyword within first 60 characters
- Total length: 60-70 characters (fully visible in search)
- Numbers and brackets increase CTR
- No clickbait — YouTube penalizes high abandon rate

## 2. Description Template

```
[First 2-3 sentences — include primary keyword, summarize video]

📌 TIMESTAMPS
00:00 — Introduction
[MM:SS] — [Chapter title]
[MM:SS] — [Chapter title]

🔗 RESOURCES MENTIONED
- [Tool/link 1]
- [Tool/link 2]

🔔 SUBSCRIBE for weekly tips!

#keyword1 #keyword2 #keyword3
```

## 3. Tags Strategy

- First tag: exact-match title keyword
- 5-10 variations of primary keyword
- 3-5 broad category tags
- 2-3 branded tags (SEOSONA, ChiQuyetAcademy)
- Total: 15-20 tags, each < 30 characters

## 4. Video Analytics — Key Metrics

| Metric | Target | Action if Low |
|:-------|:-------|:-------------|
| Click-through Rate (CTR) | > 5% | Fix Thumbnail + Title |
| Avg View Duration | > 50% | Fix script pacing, Hook |
| Retention Cliff | < 30% drop at start | Improve Hook |
| Like Ratio | > 95% | Check controversial content |
| Comments per 1000 views | > 5 | Ask questions in video |

## 5. Platform Specifications
